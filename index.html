01 / INSIGHT

Everyday objects. Personal statements.

手機是每天最常出現在手上的配件。以穿搭的配色思維，把個人情緒轉成可隨身攜帶的圖像表達。這是創作假設，並非已驗證的市場研究。

02 / DESIGN SYSTEM

One voice. Four moods.

用統一字體、鮮明留白與可替換色盤，串連四組原創圖案：流動曲線、金屬星芒、棋盤及字體拼貼。

03 / ADAPTATION

Built for every canvas.

從產品背板到社群貼文、直式Story及電商橫幅，依比例調整字級、產品位置和視覺層次，並支援中英文版本。

04 / EXECUTION

Original graphics. Live 3D.

圖案以Canvas繪製；產品透過Three.js即時呈現立體厚度、鏡頭框、材質與掛飾。平面圖稿與活動素材可直接匯出。
